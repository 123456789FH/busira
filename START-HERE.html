فتح التطبيق

كيف أرفعه وأشاركه مع الجميع؟

  1. فكّي ضغط الحزمة أولًا.
  2. أنشئي مستودعًا عامًا في GitHub. من Add file → Upload files ارفعي الملفات ومجلد assets، بحيث يكون index.html في جذر المستودع مباشرة.
  3. احفظي الملفات عبر Commit changes.
  4. افتحي Settings → Pages، واختاري Deploy from a branch ثم main و/(root) واضغطي Save.
  5. افتحي رابط الموقع الذي يظهر بعد اكتمال النشر، وشاركي الرابط مع المعلمين والمعلمات.

لا ترفعي ملف ZIP نفسه. ارفعي محتوياته بعد فك الضغط، دون وضعها كلها داخل مجلد إضافي.

أول تجربة داخل التطبيق

اضغطي «جرّب بورقة تدريبية». أو أنشئي اختبارًا، وأدخلي مفتاحه، ثم اطبعي نموذجه. بعد التظليل، ارفعي صورة الورقة وراجعي القراءة قبل اعتماد الدرجة. يوفّر التطبيق تحليل الأسئلة والمهارات وتصدير النتائج إلى Excel.

قبل تصحيح اختبارات حقيقية

التطبيق يقرأ نموذج بصيرة الخاص به، وليس أي ورقة تظليل عشوائية. جرّبي أوراقًا مطبوعة وقارني النتيجة يدويًا؛ الطباعة والتصوير والتظليل تؤثر في القراءة. اختيرت آلية المراجعة لتأكيد الخانات غير الواضحة قبل الحفظ.

بيانات كل مستخدم مستقلة

لا يحتاج المستخدم إلى حساب، وتبقى بياناته في متصفحه. ليست هناك مزامنة تلقائية؛ تنزيل نسخة احتياطية هو وسيلة النقل إلى جهاز آخر. لا ترفعي ملفات النسخ الاحتياطية إلى مستودع عام، لأنها تتضمن الأسماء والدرجات.

للتفاصيل: افتحي «دليل الاستخدام» داخل التطبيق، أو ملف README.md المرفق.
