# بصيرة — من الإجابة إلى الفهم

تطبيق عربي لتصحيح أوراق التظليل وتحليل النتائج، جاهز للنشر على **GitHub Pages**. يعمل في المتصفح دون تسجيل، أو اشتراك، أو خادم قواعد بيانات، أو مفاتيح API.

إعداد: **أ/ فاطمة هزازي — ملتقى معلمي ومعلمات الرياضيات — ملتقى التعليم التفاعلي**.

## الرفع إلى GitHub Pages

١. فك ضغط الحزمة على جهازك.

٢. أنشئ مستودعًا عامًا جديدًا، أو استخدم مستودعًا مخصصًا للتطبيق.

٣. من **Add file → Upload files** ارفع محتويات الحزمة. يجب أن يظهر `index.html` في جذر المستودع مباشرة، وبجانبه `app.js` و`omr.js` و`style.css` ومجلد `assets`. لا ترفع ملف ZIP نفسه، ولا تضع الملفات كلها داخل مجلد إضافي.

٤. احفظ الملفات باستخدام **Commit changes**.

٥. افتح **Settings → Pages**. ضمن **Build and deployment** اختر **Source: Deploy from a branch**، ثم الفرع **main** والمجلد **/(root)**، واضغط **Save**.

٦. انتظر اكتمال النشر وافتح الرابط الذي يظهر في صفحة Pages. شارك **رابط الموقع** مع المستخدمين، وليس رابط ملفات المستودع.

لا توجد خطوة تثبيت حزم أو بناء للتطبيق. تُحمّل جميع الملفات والخطوط من المسارات النسبية نفسها، فيعمل داخل مستودع فرعي أيضًا.

[إرشادات GitHub الرسمية لمصدر النشر](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## تجربة سريعة

يمكن فتح `index.html` مباشرة لاستكشاف الواجهة. للاستخدام المعتاد والكاميرا وإمكانية العمل دون اتصال بعد تحميل الموارد، استخدم رابط HTTPS المنشور. قد تختلف آلية الحفظ عند فتح الملفات مباشرة بين المتصفحات.

في الصفحة الرئيسية اضغط **جرّب بورقة تدريبية**. ينشئ التطبيق صورة اختبار مصطنعة ويقرأها بمحرك التصحيح الفعلي. تتضمن إجابة خاطئة، وإجابة فارغة، وتظليلًا مزدوجًا؛ وتظهر الدرجة الأولية **٧ من ١٠**. لا يُحفظ هذا المثال ضمن نتائج المستخدم.

## دورة الاستخدام

١. **الاختبارات → اختبار جديد:** أدخل العنوان، وعدد الأسئلة، وعدد الخيارات، ثم حدد مفتاح الإجابات. يمكن إسناد مهارة ووزن لكل سؤال.

٢. **النموذج:** اطبع نموذج الإجابة A4 أو احفظه PDF من نافذة الطباعة. اختر حجمًا فعليًا أو ملاءمة دون قص، وأوقف رؤوس وتذييلات المتصفح. الأسئلة نفسها تُقدّم في ورقة منفصلة.

٣. **التصحيح:** اختر الاختبار الصحيح، وارفع صورة JPG أو PNG أو WEBP، أو استخدم الكاميرا. يمكن رفع عدة صور وتصحيحها بالتتابع. أظهر المربعات الأربعة والعلامة القصيرة قرب المربع العلوي الأيسر، واجعل العنوان في الأعلى.

٤. **المراجعة:** أدخل الاسم أو الرمز. راجع اختيارات القارئ البصري؛ يجب تأكيد الخانات الفارغة أو الملتبسة قبل اعتماد الدرجة. يمكن تعديل أي إجابة. عند فشل التعرف التلقائي، حدّد مراكز المربعات الأربعة يدويًا بالترتيب الموضح.

٥. **النتائج والتحليل:** راجع درجات الطلبة، وتحليل كل سؤال، ومؤشرات المهارات، وأولوية التدريب. نزّل CSV لفتحه في Excel أو اطبع التقرير.

٦. **الإعدادات:** نزّل نسخة احتياطية بانتظام. لاستعمال جهاز آخر، استورد النسخة هناك. يمكن تصدير اختبار بمفتاحه ومهاراته فقط لمشاركته مع المعلمين، دون بيانات الطلبة.

## نطاق الإصدار

- من سؤال واحد إلى ١٠٠ سؤال في الصفحة، ومن خيارين إلى خمسة خيارات.
- إجابة صحيحة واحدة لكل سؤال؛ يمكن استخدام سؤال صح/خطأ باختيار خيارين.
- وزن السؤال من ٠٫٥ إلى ١٠٠ درجة؛ الدرجة الافتراضية ١.
- نماذج عربية ثابتة مواضع الدوائر، مع علامات محاذاة وتصحيح منظور.
- فحص علامة الاتجاه لمنع اعتماد ورقة مقلوبة أو نموذج غير مطابق للعلامة.
- حالات واضحة، وفارغة، ومتعددة، وغير مؤكدة؛ لا تُحسم الحالة الملتبسة بتخمين.
- يُحسب الفراغ ضمن الدرجة الكلية ولا يُعد صحيحًا. مؤشرات المهارات مرجّحة بدرجات الأسئلة.
- منع تعديل مفتاح اختبار له نتائج؛ يُنسخ الاختبار أولًا للمحافظة على سلامة النتائج السابقة.
- تأكيد قبل استبدال نتيجة طالب/ـة متكرر أو استعادة نسخة احتياطية كاملة.
- واجهة للجوال والكمبيوتر، وخطوط عربية محلية، ووضع ليلي، ودليل داخل التطبيق.
- حد رفع الصورة ٢٠ ميجابايت، وحتى ١٠٠ صورة في الدفعة، ومعالجة صورة واحدة في كل مرة.

**التطبيق مصمم لنماذجه الخاصة فقط.** لا يُفترض توافقه مع أوراق ZipGrade أو أي نموذج خارجي مختلف. لا يصحح الكتابة اليدوية أو خطوات الحل، ولا يقرأ أسماء الطلبة أو يحدد هوية الاختبار من الصورة تلقائيًا. يجب اختيار المفتاح المطابق للورقة.

## حدود التحقق قبل الاستخدام الفعلي

اختُبر محرك القراءة آليًا على صور مصطنعة بأعداد مختلفة من الأسئلة والخيارات، مع ميل منظور، ودقة أقل، وضوضاء، وتدرج إضاءة، وخانات فارغة، وتظليل مزدوج. واختُبر إنشاء اختبار ورفع صورة واعتماد النتيجة والتحليل وتصدير CSV واستيراد اختبار عبر المتصفح.

لم يُختبر هذا الإصدار على كاميرا جهازك أو طابعتك الفعلية. جودة الورق والحبر والممحاة والظلال والوهج تؤثر في القراءة. قبل اعتماد درجات حقيقية، اطبع عدة أوراق وجرّبها وقارنها بتصحيح يدوي. تظل المراجعة البشرية لازمة لكل نتيجة. نسبة ٧٥٪ المستخدمة في تنبيه المهارات عتبة مساعدة وليست معيار نجاح رسميًا.

## البيانات والخصوصية

التطبيق لا يرسل صور الأوراق أو النتائج إلى أي خادم، ولا يحتوي على أدوات تتبع أو إعلانات أو اتصالات بخدمات ذكاء اصطناعي. الصور تُعالَج في الذاكرة، ولا تُحفظ ضمن النسخ الاحتياطية. الاختبارات والنتائج وقائمة الطلبة تحفظ في `localStorage` الخاص بالمتصفح.

نشر الملفات لا ينشر نتائج استخدام التطبيق. لكن **ملف النسخة الاحتياطية يحتوي على الأسماء والدرجات؛ لا ترفعه إلى مستودع عام**. لكل متصفح وجهاز بيانات مستقلة، ولا توجد مزامنة تلقائية. مسح بيانات الموقع أو استعمال التصفح الخاص قد يفقد العمل.

من يستخدم المتصفح نفسه على جهاز مشترك يستطيع رؤية البيانات المحفوظة. لا توجد كلمة مرور أو صلاحيات متعددة في هذا الإصدار. استخدم ملف متصفح مستقل، أو صدّر بياناتك وامسحها بعد الاستخدام. التخزين المحلي في المواقع يتبع نطاق الاستضافة؛ لذلك يُنصح بمستودع/نطاق مخصص دون أكواد أخرى غير موثوقة على النطاق نفسه.

## الملفات

| الملف | الغرض |
|---|---|
| `index.html` | مدخل التطبيق |
| `app.js` | الاختبارات والمراجعة والتقارير والحفظ |
| `omr.js` | قراءة التظليل، والمحاذاة، وحساب الدرجات |
| `style.css` | تنسيق العربية والجوال والطباعة |
| `assets/` | الأيقونة والخطوط المحلية وترخيصها |
| `sw.js` | تخزين ملفات الواجهة للعمل دون اتصال بعد تحميلها بنجاح |
| `manifest.webmanifest` | تعريف تطبيق الويب |
| `START-HERE.html` | دليل مختصر قابل للفتح على الجهاز |
| `tests/core.test.cjs` | اختبارات محرك القراءة والحساب |
| `.nojekyll` | نشر الملفات كما هي على GitHub Pages |

التثبيت على الشاشة الرئيسية وإتاحة الكاميرا يعتمدان على المتصفح ونظام الجهاز ووجود HTTPS. لا يشترط التثبيت لاستخدام التطبيق من الرابط.

## للمطور

لا توجد تبعيات خارجية. لتشغيل الاختبارات عند وجود Node.js:

```sh
node tests/core.test.cjs
```

عند تحديث ملفات الواجهة، غيّر رقم إصدار التخزين المؤقت في `sw.js` حتى يحصل المستخدم على الموارد الجديدة. لا تغيّر المفتاح أو بنية بيانات `localStorage` دون ترحيل البيانات. لا تضف أدوات تتبع أو رفع صور إلى الخادم دون إيضاح ذلك للمستخدمين.
